# Stage 01 engine evaluation — GS-v1

Scope: only the environment and a fixed balanced-profile probe. No HTTP API,
worker, production adapter, eligibility policy, resizer or pipeline is built.
The exact results and measurements are recorded below after the real probe.

## Reproduce

```sh
make integration                 # build QA and run owned fixture checks
# This host Docker refuses all execs with no-new-privileges:
make integration SECURITY_OPT=   # locally verified equivalent except that flag
make probe                       # same CLI checks without independent Poppler
make fixtures                    # optional fixture regeneration; changes hashes
./scripts/check-test-dependencies.sh
```

Each run requires a new output directory, generated by RUN_ID by default.
`make integration RUN_ID=my-run` writes `artifacts/stage-01/my-run-qa/report.json`.
Use `DOCKER=/path/to/docker` if needed. Do not run `make fixtures` unless changing
owned fixture bytes is intended. There are no unit tests at this stage;
`make unit` prints that fact after the inventory and never runs Go tests.

Both containers use a read-only root filesystem, disabled network, unprivileged
host UID/GID, dropped capabilities, no-new-privileges, 2 GiB RAM, 2 CPU and 128 PID.
Only the artifacts directory and bounded tmpfs are writable. Probe images do
not contain Poppler or Python; QA adds these only for independent validation.

## Frozen inputs

* Go **1.27.2**, only standard library, build image pinned by OCI digest.
* Ghostscript **10.08.0**, AGPL build from official source. User approved replacing
  unavailable 10.09.0 (release gs10090 returned 404 on 2026-10-09).
* qpdf **12.4.2**, Apache-2.0 build from official source.
* Ubuntu 24.04 base pinned by OCI digest; build/runtime/QA APT dependencies use
  **20261008T000000Z** package snapshot, with failure on unavailable indexes.
* Exact source hashes are in Dockerfile; the complete source archives, upstream
  license notices, fonts/resources, build configuration and installed package
  manifests are retained in each image. No activation key is provided.

## Fixed settings and evidence format

`cmd/engine-probe/main.go` embeds the exact balanced arguments/settings from the
contract, including color/gray 300 dpi/Bicubic, threshold 1.1, mono downsampling
false, JPEG/JPX passthrough, SAFER, fonts and Link preservation settings. The
trusted settings include NeverEmbed=[], QFactor=0.4 and H/V samples [1 1 1 1].
No PDFSETTINGS preset is used. Production profile code belongs to Stage 04.

`report.json` stores every gs/qpdf/Poppler argv, exit code, stdout/stderr, versions,
original/output byte counts, image dimensions, text/geometry/semantic assertions
and SAFER denial results. qpdf JSON files and original/candidate txtwrite files
are saved next to PDFs. Independent Poppler full-page PNGs permit visual review.
Lossless full-page 600-dpi decoded pixels must match exactly; GS mono decoded image pixels must match exactly; independent 600-dpi
page-crop equality is separately recorded, with differences left as an explicit
Stage 07 release gate. The JBIG2 source crop must also match the owned
mono Flate source crop, guarding against a falsely passing inverted fixture.

Geometry and semantic comparison here covers deliberately simple one-page
fixtures with fixed boxes, one URI Link and a /Fit bookmark. It is not a generic
production semantic validator. A feature difference is explicitly reported as
RequiresSemanticFallback and requires the Stage 05 lossless/original fallback.

## Limits of this evidence

A positive codec fixture proves that selected build decodes and rewrites that
fixture, not every possible stream. JPX covers lossless RGB JPEG2000; JBIG2 covers
an MMR generic region without globals/symbol dictionaries. Full codec edge cases,
OCR/Cyrillic/embedded fonts, masks, transparency, complex colors, rotation/UserUnit,
shared images, compact 150-dpi output, QR/barcode and load acceptance are left to
Stages 04/07. This stage does not claim release readiness or image quality based
only on matching dimensions or text.

## Actual verified results — 2026-10-09

`make integration RUN_ID=verified SECURITY_OPT=`: **exit 0**, 16 candidates; 14 Pass and two RequiresVisualFollowup. Separate `make probe RUN_ID=verified SECURITY_OPT=`: **exit 0**, 16 local CLI checks, QA=false.

| Fixture | Original bytes | qpdf bytes | GS bytes | GS pixels / effective dpi | Outcome |
|---|---:|---:|---:|---|---|
| jpeg-600dpi.pdf | 111918 | 111746 | 227668 | 600 × 600 / 300 | Pass |
| flate-rgb-600dpi.pdf | 561006 | 560394 | 50027 | 600 × 600 / 300 | Pass |
| jpeg-150dpi.pdf | 11495 | 11320 | 15567 | 300 × 300 / 150 | Pass |
| flate-rgb-150dpi.pdf | 202756 | 202584 | 16200 | 300 × 300 / 150 | Pass |
| flate-gray-600dpi.pdf | 28626 | 24433 | 11598 | 600 × 600 / 300 | Pass |
| mono-flate-600dpi.pdf | 1657 | 1439 | 15922 | 1200 × 1200 / 600 | RequiresVisualFollowup |
| jbig2-600dpi.pdf | 11868 | 11693 | 15922 | 1200 × 1200 / 600 | RequiresVisualFollowup |
| jpx-600dpi.pdf | 84136 | 83964 | 50026 | 600 × 600 / 300 | Pass |

Effective DPI was independently verified from actual Poppler `pdfimages -list` output, not only derived from width. All 16 candidates pass strict qpdf check, gs txtwrite and independent pdftotext comparison, physical page boxes/default rotation/UserUnit, URI link rectangle/action and bookmark destination checks.

Eight lossless independent render comparisons match exactly: six full pages at 600 dpi and two mono image crops at 600 dpi. Both mono GS outputs preserve 1200 × 1200 decoded image pixels exactly, including JBIG2 versus the synthetic Flate reference. Their full-page image crops differ at some edges in Poppler; **the cause remains unresolved**. This is a named Stage 07 visual release gate, not a visual-fidelity Pass. The fixed content matrices express the same mathematical placement; the probe does not resolve the rendering difference.

Independent 72-dpi full-page RGB/JBIG2 PNG spot review showed the expected image area and readable fixed text. This does not replace Stage 07 quality checks. No text, page-box, Link or bookmark loss occurred in these fixtures, so no semantic fallback was needed here. Stage 05 must still validate real candidates.

JPEG 600/150 dpi and mono GS outputs are larger than their originals. The Stage 05 smallest-valid selection is required; this probe intentionally reports the raw engine result and never promises a compression percentage.

SAFER permitted the fixed input/output paths and rejected both adjacent-file reads and writes with invalidfileaccess. Core fonts resolve without stderr diagnostics after setting XDG_CACHE_HOME=/tmp/cache. Ghostscript compiles its Font/Init/CMap resources into `%rom%`; the absence of a Resource/Font filesystem directory is expected and does not indicate missing fonts. Build logs and the retained source archive contain the font/resource notices.

Local Snap Docker 29.8.0 refuses every executable (including /bin/sh and gs) when no-new-privileges is set: exit 255, operation not permitted. The default Makefile keeps the flag; the recorded local runs use SECURITY_OPT= while retaining non-root UID, read-only rootfs, cap-drop ALL, no network and resource limits. Recheck the flag in the deployment environment at Stage 06.

Artifacts: `artifacts/stage-01/verified-qa/`, `verified-probe/`, `verified-qa.log`, `verified-probe.log`, `build-pinned.log`, `build-final.log`, `images.json`, `runtime-evidence.txt`, `fonts-and-library-checksums.txt`, `probe-target-evidence.txt`. The persistent [lock](engine-evaluation-lock.json) retains image IDs and binary/source/library checksums. Large artifacts are ignored by Git.

Initial diagnostics are retained: the first no-new-privileges attempt failed before processing; `initial-qa` failed on Fontconfig cache diagnostics; `font-cache-qa` exposed the separate mono crop difference. The JBIG2 generator initially included a forbidden end-of-page segment and opposite TIFF polarity; host Poppler sanity checking identified them, they were corrected, and the final baked fixture passed selected-build decoder checks. These initial checks are not acceptance evidence.

## Stage 04 profile calibration & results — 2026-10-09

Stage 04 implemented production profile configuration in `internal/ghostscript/{profiles,settings,diagnostics}.go` and verified balanced, compact, and lossless contracts across all 8 fixtures.

`make integration RUN_ID=stage04-qa-test SECURITY_OPT=`: **exit 0**, 24 candidates across 8 fixtures (lossless, balanced, compact). All 24 pass strict qpdf check, gs txtwrite, pdftotext, physical geometry, URI links and bookmark destination assertions.

| Fixture | Original bytes | Lossless bytes | Balanced bytes (300 DPI) | Compact bytes (150 DPI) | Outcome |
|---|---:|---:|---:|---:|---|
| jpeg-600dpi.pdf | 111918 | 111746 | 227668 (600×600) | 65531 (300×300) | Pass |
| flate-rgb-600dpi.pdf | 561006 | 560394 | 50027 (600×600) | 16209 (300×300) | Pass |
| jpeg-150dpi.pdf | 11495 | 11320 | 15569 (300×300, not upsampled) | 15569 (300×300, not upsampled) | Pass |
| flate-rgb-150dpi.pdf | 202756 | 202584 | 16202 (300×300, not upsampled) | 16202 (300×300, not upsampled) | Pass |
| flate-gray-600dpi.pdf | 28626 | 24433 | 11600 (600×600) | 8876 (300×300) | Pass |
| mono-flate-600dpi.pdf | 1657 | 1439 | 15922 (1200×1200, no downsample) | 15922 (1200×1200, no downsample) | Pass (Visual Followup Stage 07) |
| jbig2-600dpi.pdf | 11868 | 11693 | 15922 (1200×1200, no downsample) | 15922 (1200×1200, no downsample) | Pass (Visual Followup Stage 07) |
| jpx-600dpi.pdf | 84136 | 83964 | 50026 (600×600) | 16208 (300×300) | Pass |

Key findings:
1. Compact profile achieves significant size reductions (e.g., `flate-rgb-600dpi.pdf` reduced from 561 KB to 16.2 KB, `jpeg-600dpi.pdf` from 111.9 KB to 65.5 KB).
2. 150-DPI fixtures are not upsampled (`DownsampleThreshold=1.1` ensures no upsampling occurs).
3. 1-bit monochrome images are never downsampled (`DownsampleMonoImages=false` preserves 1200×1200 exact dimensions without loss).
4. Lossless profile strictly refuses Ghostscript rewrite args (`ErrLosslessNoRewriteArgs`).
