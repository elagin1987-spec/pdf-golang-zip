# GS-v1 third-party software

Baseline GS-v1: Go 1.27.2, **Ghostscript 10.08.0**, qpdf 12.4.2.
Ghostscript 10.08.0 replaces the unavailable 10.09.0 release with user approval
on 2026-10-09. No commercial license or activation key is used.

* Ghostscript: Artifex Software and contributors, GNU AGPL v3 or later.
  Its `LICENSE` (including the Resource/Font embedding exception) and full
  `doc/COPYING` are installed at `/opt/pdf-tools/share/doc/ghostscript/`.
  Built-in resources include Nimbus fonts, CMaps, ICC profiles and interpreter
  initialization files. Bundled third-party components include OpenJPEG,
  jbig2dec, JPEG, zlib, libpng, FreeType and Little CMS; their complete upstream
  notices and source are retained in `share/doc/sources/gs.tar.xz`.
* qpdf: Jay Berkenbilt and contributors, Apache License 2.0.
  `share/doc/qpdf/LICENSE.txt` and the full source archive
  `share/doc/sources/qpdf.tar.gz` retain upstream notices.
* Go: The Go Authors, BSD 3-clause. The BSD LICENSE is retained at `/usr/share/doc/pdf-tools/GO-LICENSE`; the probe, server and worker use Go standard-library and local project packages only.
* Ubuntu runtime packages and their libraries: copyright/license files at
  `/usr/share/doc/<package>/copyright`; the APT snapshot is 20261008T000000Z; installed versions in
  `/usr/share/doc/pdf-tools/runtime-packages.txt`. Fontconfig/font packages are
  included to keep resource lookup functional.
* QA only: Poppler (GPL) and Pillow (HPND), with their packaged copyright files.
  QA package versions are saved in `/usr/share/doc/pdf-tools/qa-packages.txt`.

Source URLs and SHA-256 hashes are literal constants in `Dockerfile`. Both
complete CLI source archives and build configuration records are preserved in
images. No Ghostscript modifications are applied. This inventory records the
included software; it is not a legal conclusion about service integration.
Synthetic fixture PDFs are generated by this project and contain no private data.

## Stage 07 QA fixture font

Synthetic `testdata/pdf/text-ocr-vectors.pdf` embeds a DejaVu Sans subset generated
from the host's fonts-dejavu-core package. DejaVu changes are public domain;
Bitstream Vera font permission and copyright notice are preserved in
`testdata/pdf/dejavu-font-license.txt`. The fixture generator uses reportlab,
pypdf and Pillow only for QA; production remains Go + Ghostscript + qpdf.
The independent zbar symbol decoder is included only in the quality-test target.
